# Правила для агентів і людей

Сайт кафедри комп'ютерної інженерії КНУ. Статичний: результат збирання — лише HTML, CSS, JS і зображення в `dist/`.

## Стек
- Astro 7 (SSG), без фреймворку інтерфейсу. Стилі — UI-кіт «Сигнал» (`src/styles/tokens.css`, `kit.css`) + `site.css`.
- Node 24. Команди: `npm ci`, `npm run dev`, `npm run build`, `npm run check:content`, `npm test`, `npm run lhci`.

## Вміст
- Новини: `src/content/news/{uk,en}/<slug>.md`; сторінки: `src/content/pages/{uk,en}/`; люди: `src/content/people/{uk,en}/`.
- Файл з тією самою назвою в `uk/` і `en/` — дві мовні версії одного матеріалу. Нова новина = два файли; код не змінюється.
- Поля шапки перевіряє схема `src/content.config.ts`. Шаблон новини — `docs/templates/news.md`.
- Зображення вмісту — `src/assets/images/…` (стискаються під час збирання), документи — `public/files/…`.
- Адреси чинного сайту збережено: `/posts/<slug>/`, `/personas/<slug>/`, `/<сторінка>/`; англійська — з префіксом `/en/`.
- Терміни для перекладу — `docs/glossary.md`.

## Гілки й запити на злиття
- Гілки: `feature/…`, `fix/…`, `content/…`, `ci/…`, `docs/…`. Пряма зміна `main` заборонена.
- Запит на злиття — з описом і `Closes #N`; потрібні рецензія іншого учасника й зелені перевірки CI.

## Заборони
- Без серверної частини, без зовнішніх CDN і трекерів; шрифти й скрипти — лише локальні.
- Паролі, ключі, токени й персональні дані — не в репозиторій і не агентам.
- Кольори — лише через токени; рух — з `prefers-reduced-motion`; кожне зображення — з `alt`.
- Не змінювати `current-site/` (копія чинного сайту — джерело для перевірки повноти).
