# Сайт кафедри комп'ютерної інженерії КНУ

Статичний сайт на Astro з дизайном «Сигнал». Вміст — Markdown у `src/content/` українською й англійською.

```sh
npm ci
npm run dev          # http://localhost:4321
npm run build        # dist/ — готові статичні файли
npm run check        # повнота вмісту + автотести
```

- Як додати новину — [docs/CONTENT.md](docs/CONTENT.md)
- Як розгорнути на сервері КНУ — [docs/DEPLOY.md](docs/DEPLOY.md)
- Правила для команди й агентів — [AGENTS.md](AGENTS.md)
