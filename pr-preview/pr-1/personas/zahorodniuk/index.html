Загороднюк Сергій Петрович

кандидат фізико-математичних наук, доцент

Фігура Ліссажу · 3:4

Основна інформація

Народився 25 липня 1976 р. в м. Києві. Освіта: Київський університет імені Тараса Шевченка, радіофізичний факультет, спеціальність «Радіофізика і електроніка», ОКР «магістр», випуск 1999 р. Індустріальна сертифікація: Microsoft Certified Professional (з 1999 р.), Microsoft Certified System Engineer (з 2000 р.), Microsoft Certified Trainer (з 2001 р.), Microsoft Office Master (з 2004 р.).

Основні напрямки діяльності – проведення спеціалізованих курсів, доповідей, семінарів, консультаций за наступними темами:

  • системне адміністрування серверних операційних систем Microsoft Windows (Windows Server NT 4.0/2000/2003/2008/2012)
  • налаштування мережевих служб на платформі Windows Server: Active Directory, Terminal Services, SharePoint Services, Internet Information Services + ASP.NET + PHP, Certificate Server, DNS, DHCP, SNMP, NAT, VPN, DIAL-UP, WMI, Firewall, Web Proxy, SOCKS Proxy
  • налаштування баз даних на платформах Windows Server + MSSQL, Linux + MySQL
  • адміністрування програмного комплексу для організаціх колективної взаємодії Microsoft Exchange Server, розробка для нього ASP.NET-інтерфейсів і транспортних агентів протоколу SMTP
  • адміністрування програмних корпоративних шлюзів Microsoft ISA Server і Microsoft TMG Server, розробка плагінів
  • розробка моніторингових та поліцейских служб за допомогою середовищ програмування PowerShell, Windows Scripting Host, Visual Studio 2008/2012/2013
  • налаштування тонких клієнтів за протоколами DHCP/TFTP
  • адміністрування засобів безпеки: цифрові підписи і шифрування даних, файлова система EFS, прикладні програми для захисту інформації, безпечна електронна пошта S/MIME і PGP, захист транспортування даних за протоколами тунелювання SSL/TLS, SSH, VPN, IPSec, системи виявлення мережевих атак (intrusion detection systems)
  • адміністрування і програмування служб автоматичних оновлень Windows Software Update Server (WSUS)

Додаткові напрямки діяльності:

  • адміністрування і підтримка клієнтських ОС DOS, Windows, Linux
  • адміністрування и розробка макросів і плагінів для Microsoft Office (Word, Excel, PowerPoint, Outlook)
  • адміністрування програм сімейства Microsoft System Center
  • розробка засобів архівації та відновлення
  • аналіз операційних систем на наявність вірусів і шпигунського програмного забезпечення
  • адміністрування служб Microsoft Media Services, оцифровка, кодування та конвертація аудіо-відеоматеріалів, online/offline-трансляція теле-радіо-відео-аудіо-сигналів
  • монтаж і налагодження телефонного обладнання і комунікаційного програмного забезпечення
  • монтаж і налагодження антенних комплексів та обладнання для ефірного телебачення, супутникового телебачення, радіомовлення, дистанційного навчання та відеоконференцій
  • адміністрування операційних систем Novell Netware, FreeBSD, Linux, Cisco IOS

Додаткова інформація

Хоббі: ремонт і налаштуання ретро-апаратури, автотюнінг, подорожі, відвідування технічних форумів і виставок, активний відпочинок (плавання, теніс, ковзани), театр.
