## General information

Born on 25 July 1976 in Kyiv. Education: Taras Shevchenko University of Kyiv, Faculty of Radiophysics, speciality "Radiophysics and Electronics", educational qualification level "Master's", graduated in 1999. Industry certifications: Microsoft Certified Professional (since 1999), Microsoft Certified System Engineer (since 2000), Microsoft Certified Trainer (since 2001), Microsoft Office Master (since 2004).

Main areas of activity: delivering specialised courses, talks, seminars and consultations on the following topics:

- system administration of Microsoft Windows server operating systems (Windows Server NT 4.0/2000/2003/2008/2012)
- configuration of network services on the Windows Server platform: Active Directory, Terminal Services, SharePoint Services, Internet Information Services + ASP.NET + PHP, Certificate Server, DNS, DHCP, SNMP, NAT, VPN, DIAL-UP, WMI, Firewall, Web Proxy, SOCKS Proxy
- configuration of databases on the Windows Server + MSSQL and Linux + MySQL platforms
- administration of the Microsoft Exchange Server collaboration software suite, development of ASP.NET interfaces and SMTP transport agents for it
- administration of the Microsoft ISA Server and Microsoft TMG Server corporate software gateways, plugin development
- development of monitoring and policy-enforcement services using the PowerShell, Windows Scripting Host, and Visual Studio 2008/2012/2013 programming environments
- configuration of thin clients over the DHCP/TFTP protocols
- administration of security tools: digital signatures and data encryption, the EFS file system, information security applications, secure email S/MIME and PGP, protection of data in transit using the SSL/TLS, SSH, VPN, IPSec tunnelling protocols, network intrusion detection systems
- administration and programming of the Windows Software Update Server (WSUS) automatic update services

Additional areas of activity:

- administration and support of the DOS, Windows, Linux client operating systems
- administration and development of macros and plugins for Microsoft Office (Word, Excel, PowerPoint, Outlook)
- administration of the Microsoft System Center family of products
- development of backup and recovery tools
- scanning operating systems for viruses and spyware
- administration of Microsoft Media Services, digitisation, encoding and conversion of audio and video materials, online/offline broadcasting of TV, radio, video and audio signals
- installation and setup of telephone equipment and communication software
- installation and setup of antenna systems and equipment for terrestrial television, satellite television, radio broadcasting, distance learning and video conferencing
- administration of the Novell Netware, FreeBSD, Linux, Cisco IOS operating systems

## Additional information

Hobbies: repairing and tuning retro equipment, car tuning, travelling, attending technical forums and exhibitions, active leisure (swimming, tennis, ice skating), theatre.
